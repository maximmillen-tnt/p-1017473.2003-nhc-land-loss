The `status.md` convention now covers every submodule of `exposure`, `hazard`
and `vul`, not just the hazard modules. The file sits at the submodule's own
level — `exposure/<asset>/`, `hazard/<hazard>/`, `vul/<hazard>/<asset>/` — and
the `maintaining-status-files` skill gains the mapping, a note that a change can
reach both a hazard file and its downstream `vul` file, and a weekly-update
procedure that globs all of them rather than only `hazard/`.

`hazard/landslide/status.md` records that the ESNZ probabilistic landslide model
is confirmed to be the same GNS model held in PRUE which **L-08** restricts to
cross-comparison; the team may still adopt it as the primary model, so that
register entry needs revisiting if the extend route is chosen.
