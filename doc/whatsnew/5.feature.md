Added `landloss.io.readers.get_nz_river_name_lines` for the LINZ NZ River Name
Lines layer, and `landloss.hazard.waterways`, which tags each watercourse as a
named river or as other so the major rivers can be told apart from streams and
creeks. Map styling shared with the National Liquefaction Model is now available
as `landloss.common.utils.plot.style_basemap_ax`, and
`src/scripts/landloss/hazard/report/fig_waterway_map.py` uses all three to draw
the waterways across the study area. Figures are written to `report/` and are not
tracked.
