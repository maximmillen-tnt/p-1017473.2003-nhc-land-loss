Added `landloss.io.nlm`, a reader for the National Liquefaction Model's own
scenario release tree (`T:\Auckland\Projects\1017473\WorkingMaterial\
new_versioned_releases`, shared across every subproject under 1017473 rather
than owned by this study). `get_nlm_scenario_rp2500y_gwd_med_p_ld_moderate_fu`
reads the RP2500y, median groundwater, moderate land damage grid from the
release pinned by the new `CORE_NLM_VERSION` constant; `get_nlm_scenario_raster`
and `nlm_release_path` are the general-purpose reader and path resolver behind
it for any other file under the same tree.

`tdrive_sync` gains `get_cached`, a generic counterpart to `get_source_mat` for
a caller with its own absolute T: path rather than one under
`SOURCE_MATERIAL_DIR`: read-only, no `DATA_VERSION`, no save side, and no
local-only working mode fallback — it just mirrors the given path into the
local cache and refreshes it when stale. `landloss.io.nlm` is its first user.
